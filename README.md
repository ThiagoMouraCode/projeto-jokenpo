
🪨✂️📄 Projeto Jokenpô (C)

Desenvolvido por Thiago Moura — um projeto simples e eficiente em C, recriando o clássico jogo Jokenpô (Pedra, Papel e Tesoura) com foco em boas práticas e lógica de programação.


---

🧠 Objetivo

Criar um jogo interativo em C que:

Recebe a escolha do usuário (Pedra, Papel ou Tesoura);

Gera uma jogada aleatória para o computador;

Exibe o resultado final (vitória, derrota ou empate);

Demonstra uso de estruturas condicionais, funções e aleatoriedade.



---

🧩 Tecnologias utilizadas

Linguagem: C

Compilador: GCC

IDE recomendada: VS Code 



---

⚙️ Como executar o projeto

1. Clone o repositório:

git clone https://github.com/ThiagoMouraCode/projeto-jokenpo.git


2. Acesse o diretório do projeto:

cd projeto-jokenpo


3. Compile o código:

gcc main.c -o jokenpo


4. Execute o programa:

./jokenpo



---

💡 Aprendizados

Durante o desenvolvimento, foram praticados conceitos fundamentais como:

Estruturas condicionais (if, else if, else, switch);

Uso da função rand() para gerar valores aleatórios;

Manipulação de entrada e saída com printf e scanf;

Organização e clareza de código.
